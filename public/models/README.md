# Icebreakerlab — Modelos 3D

La página principal carga `/models/iceberg-web.glb`, optimizado a partir del archivo GLB proporcionado por el propietario del proyecto.

**El binario todavía NO está incluido en GitHub.** El componente `src/components/IcebergGLB.tsx` presenta una figura de respaldo hasta que se añada el modelo. La versión completa con el GLB optimizado se entrega por ZIP en ChatGPT.

Para incluir el modelo en este repositorio, subir `iceberg-web.glb` (16,65 MB) a la carpeta `public/models/` de la rama `develop`. No subir el archivo original de 51,87 MB sin comprimir.

Este repositorio es **público**; las personas podrán descargar los assets que se publiquen aquí.

Una vez subido, las compilaciones en GitHub Actions verificarán el código, pero se deben revisar también el renderizado real y la velocidad en dispositivos.
