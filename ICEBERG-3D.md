# Icebreakerlab — Modelo 3D y optimización

## Fuente
Modelo GLB facilitado para el rediseño del hero. El original ronda los 52 MB y tiene unas 500.000 caras; no se debe servir sin optimización.

## Objetivo
- Reducir tamaño de modelo y texturas sin perder su forma escultórica.
- Mantener material tipo hielo con iluminación azul/lavanda.
- Animación de rotación/parallax con cursor y flotación ambiental.
- Mantener websites como elementos HTML interactivos y accesibles.
- Cargar escena 3D de manera diferida, con un poster de respaldo.
- Comprobar visibilidad y velocidad en mobile; respetar reduced motion.

## Estado
La optimización local y la integración definitiva del archivo GLB aún no están publicadas aquí. No confundir el WebGL procedimental anterior con el GLB proporcionado.
